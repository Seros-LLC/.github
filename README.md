# .github — Seros, LLC Organization Repository

This repository holds the organization profile (`profile/README.md`) and the standard community-health defaults for [Seros-LLC](https://github.com/Seros-LLC) public repositories.

Seros, LLC is an **AI and agentic consulting firm** based in Georgia. We help leadership teams decide where AI belongs, then deliver written advice and practical systems you own. A person approves every consequential action.
